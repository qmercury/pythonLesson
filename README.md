# pythonLesson — 로보타그램 Python 프로젝트 교육과정

> SPIKE Prime에서 익힌 Python 문법을 컴퓨터 그래픽, GUI, 웹·모바일 앱 개발로 확장하는 수업 자료 저장소

## 교육과정 안내

| 과정 | 차시 | 핵심 역량 | 문서 |
| --- | ---: | --- | --- |
| **Python 크리에이티브 코딩 1 — Turtle** | 12 | 그래픽, 좌표, 이벤트, 가상 로봇 시뮬레이션 | [Turtle 커리큘럼](curriculum/turtle/README.md) |

## 수업 원칙

1. 문법을 다시 나열하기보다 **새로운 프로그램을 만들기 위해 문법을 활용**한다.
2. 완성 작품 시연 → 핵심 개념 → 기본 실습 → 응용/도전 미션 → 결과 공유로 진행한다.
3. 학생에게는 시작 코드와 미션을 주고, 기능을 스스로 설계·수정하도록 한다.
4. 각 차시 결과물을 로보타그램 포트폴리오에 짧게 기록한다.
5. 실제 로봇과 PC의 Python 라이브러리는 다를 수 있으므로 개념을 연결하되 동일한 코드가 실행된다고 가정하지 않는다.
