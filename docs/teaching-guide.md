# 교사용 공통 수업 운영 기준

## 수업 대상과 전제

- 레고 SPIKE Prime에서 Python 문법(변수, 조건문, 반복문, 함수)을 배운 초등학교 4~6학년 수준.
- 핵심 전환: '로봇을 움직이기 위한 코드' → '문제를 해결하기 위한 프로그램'.
- 개인차가 있으므로 과제는 기본·응용·도전의 3단계로 구성.

## 기본 90분 수업

| 단계 | 시간 | 활동 |
|---|---:|---|
| 문제 제시·완성작품 시연 | 10분 | 무엇을 만들며 왜 필요한지 질문 |
| 새 도구·개념 소개 | 20분 | 필요한 API만 소개, 기본 코드 실행 |
| 기본·응용 미션 | 40분 | 학생이 함수를 변경/추가하고 테스트 |
| 자기주도 확장 | 10분 | 디자인 또는 새 기능 추가 |
| 발표·포트폴리오 | 10분 | 화면 캡처, 핵심 코드 설명, 다음 계획 |

## 차시별 자료 표준

각 차시의 파일을 추가 제작할 때 다음 순서를 권장한다.

1. 교사용 지도안: 도입 질문, 성취 기준, 시범, 예상 오류, 시간 배분.
2. 학생용 시작 코드: 창과 기본 객체 등 반복적 보일러플레이트만 포함.
3. 학생용 미션 카드: 기본 2개, 응용 2개, 도전 1개.
4. 교사용 완성 예제: 기능별 주석과 실행방법 포함.
5. 포트폴리오 양식: 배운 명령어와 고친 오류를 한두 문장씩.

## 학생 과제 평가

| 요소 | 관찰할 행동 |
|---|---|
| 이해 | 코드를 바꾸면 화면·동작이 어떻게 변하는지 말한다 |
| 구현 | 기본 기능을 스스로 추가하거나 고친다 |
| 문제 해결 | 오류를 재현하고 수정한 이유를 설명한다 |
| 창의적 확장 | 자신의 사용자/규칙/디자인을 반영한다 |
| 공유 | 결과물을 다른 학생에게 시연하고 피드백을 반영한다 |

기능의 숫자나 화려함보다 원리 이해와 개선 과정을 우선한다.

## 포트폴리오 연구일지 (짧게)

1. 오늘 만든 프로그램:
2. 새롭게 사용한 코드와 역할:
3. 내가 해결한 문제 또는 수정한 기능:
4. 다음에 추가할 기능:
5. 실행 화면 캡처 첨부.

학생들의 부담을 줄이기 위해 문장당 1~2줄을 권장한다. 작품 제출 시 실명 등 개인정보를 요구하지 않는다.

## 로봇과 소프트웨어의 연결 설명

| 실제 SPIKE Prime | Turtle | Tkinter/Flet |
|---|---|---|
| 센서 입력 | 객체 좌표·거리 계산 | 버튼·키보드·폼 입력 |
| 조건문 판단 | 장애물·목표 판정 | 점수·퀴즈·오류 판정 |
| 모터 출력 | Turtle 이동/그리기 | 화면/데이터 상태 변경 |
| 로봇 주행 미션 | 가상 주행·게임 | 점수판·타이머·기록 앱 |

## 진행 현황

- 1차: 커리큘럼 전체 맵과 Tkinter 1차시 상세 지도안 작성.
- 다음: 각 차시 교사용 지도안, 학생 시작 코드, 미션 워크시트, 완성 코드 순차 제작.
- Flet 과정은 도구 버전과 교실 PC/휴대폰 네트워크 환경을 검증한 뒤 확정.
