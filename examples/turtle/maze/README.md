# Turtle 미로 탈출

Thonny에서 사용하는 로보타그램 Turtle 미로 실습입니다. 별도의 라이브러리 설치는 필요하지 않습니다.

## 수업 시작

1. Thonny의 **도구 → 시스템 셸 열기**에서 자기 Git 저장소 폴더로 이동해 `git pull`을 실행합니다.
2. `examples/turtle/maze/lesson-01.py`를 열고 같은 폴더에 **`main.py`**로 다른 이름 저장합니다.
3. `main.py`에서 `# 여기에 코드를 작성하세요.` 아래에 이동 알고리즘을 작성합니다.
4. Thonny에서 **F5**를 눌러 실행합니다.

`main.py`는 Git에 추가되지 않도록 이 폴더의 `.gitignore`에 등록되어 있습니다. `lesson-01.py`는 원본 템플릿으로 유지하세요.

## 학생이 사용할 명령

| 명령 | 기능 |
|---|---|
| `STEP = maze.start(level=1)` | 미로를 열고 한 칸의 길이를 받습니다. |
| `maze.forward(STEP)` | 한 칸 전진합니다. |
| `maze.backward(STEP)` | 한 칸 후진합니다. |
| `maze.left(90)` | 왼쪽으로 90도 회전합니다. |
| `maze.right(90)` | 오른쪽으로 90도 회전합니다. |
| `maze.wall_ahead()` | 현재 바라보는 방향으로 **한 칸 앞에 벽**이 있으면 `True`, 아니면 `False`입니다. 거북이는 움직이지 않습니다. |
| `maze.wall_ahead(20)` | 현재 방향의 앞쪽 **20만큼** 벽이 있는지 확인합니다. |
| `maze.heading()` | 현재 바라보는 각도를 반환합니다. 오른쪽 0°, 위쪽 90°, 왼쪽 180°, 아래쪽 270°입니다. |
| `maze.position()` | 현재 `(x, y)` 좌표를 반환합니다. |
| `maze.is_finished()` | 목표에 도착했다면 `True`입니다. |
| `maze.done()` | Turtle 창을 유지합니다. |

`maze.forward()`와 `maze.backward()`는 벽에 막히거나 미션이 종료되면 `False`를 반환할 수 있습니다. 긴 거리를 이동하면 벽 앞에서 일부만 이동할 수도 있습니다.

## 미션 단계

| 난이도 | 설정 | 맵 크기 | 한 칸 길이 |
|---|---|---|---|
| 쉬움 | `maze.start(level=1)` | 5 × 4 | 86 |
| 보통 | `maze.start(level=2)` | 7 × 5 | 70 |
| 도전 | `maze.start(level=3)` | 9 × 6 | 62 |

모든 학생에게 동일한 난이도와 동일한 미로가 표시됩니다. 벽을 감지하고 이동하는 알고리즘은 **학생이 직접 작성**합니다.
