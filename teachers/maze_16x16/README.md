# 교사용 정답지 — Turtle 16×16 미로

> 공개 저장소에 보관하는 교사용 예시입니다. 학생용 `qmercury/pyClass`의 `git clone`에는 포함되지 않지만, **`qmercury/pythonLesson`이 Public이므로 GitHub에서 누구나 이 정답을 열람할 수 있습니다.** 학생에게 정답을 숨겨야 한다면 비공개 저장소로 옮겨야 합니다.

## 파일

- `maze_teacher_answer.py`: 벽 그리기, 좌표 저장, 반복문·조건문, 한 칸 이동, 충돌 판정, 도착까지의 경로를 담은 정답 예시
- `robot_shape.py`: 학생용 `pyClass`와 동일한 로봇 모양. 같은 폴더에 있어야 실행됩니다.

## 실행

1. 이 폴더의 Python 파일 2개를 같은 위치에 다운로드합니다.
2. Thonny에서 `maze_teacher_answer.py`를 열고 F5를 누릅니다.
3. 16×16 격자, 검은 벽, 로봇, 목표점이 표시됩니다.
4. 로봇이 벽을 피해서 목표 지점까지 이동하며, 충돌 검사 결과를 콘솔에 출력합니다.

## 학생용 템플릿과 동일한 좌표 기준

- 화면 800×800픽셀, 격자 16×16칸(640×640픽셀)
- 화면 **왼쪽 위 = (0, 0)**, X는 오른쪽, Y는 아래쪽으로 증가
- 한 칸 40×40픽셀: `CELL_SIZE = 40`, `STEP = 40`
- 벽은 각 칸의 **왼쪽 위 픽셀 좌표**를 저장. 예: `(120, 200)`
- 로봇은 각 칸의 **중앙 픽셀 좌표**를 사용. 시작 `(20, 20)`, 도착 `(620, 620)`
- `(x,y)` 순서를 유지하고, 격자 좌표와 픽셀 좌표를 섞지 않습니다.

## 미션별 지도 포인트

### 1. 벽 한 칸 그리기

`draw_wall(x, y)`에서 벽의 왼쪽 위로 이동해 가로·세로 40픽셀의 사각형을 검게 채웁니다. `goto`, `penup`, `pendown`, `begin_fill`, `forward`, `left`, `end_fill`을 사용합니다.

### 2. 벽의 픽셀 좌표 저장

`walls = set()`에 `(x, y)`를 추가합니다. 예: `draw_wall(120, 200)`을 호출하면 `(120, 200)`이 저장됩니다. 학생에게 `in` 연산자로 벽 존재 여부를 검사하게 해 보세요.

### 3. 반복문과 조건문으로 미로 만들기

- 세로 벽: `x=120`, `y=0..480` 중 `y=240`은 통로
- 가로 벽: `y=360`, `x=160..520` 중 `x=320`은 통로
- 전체 검은 벽 21칸. 시작과 도착 지점은 비워 둡니다.

### 4. 한 칸씩 이동

`forward(STEP)`은 40픽셀 이동을 의미하며 로봇은 항상 칸 중앙에 정렬됩니다. `robot.forward()`만 사용하면 벽을 자동으로 감지하지 못합니다.

### 5. 충돌 판정

- 다음 로봇 중심 `(next_x, next_y)`를 현재 방향에서 40픽셀만큼 계산합니다.
- 벽의 왼쪽 위 좌표 `(next_x-20, next_y-20)`가 `walls`에 있는지 확인합니다.
- 다음 중심 좌표가 20~620 범위 밖이면 이동하지 않습니다.
- `forward(step)`은 양의 40픽셀 배수만 허용하고 중간 벽을 만나면 멈춥니다.

## 예시 경로와 확인 결과

1. 시작 `(20,20)`에서 오른쪽 2칸 이동하여 `(100,20)`
2. `(120,0)` 벽으로 향하는 1칸 이동은 차단
3. 아래쪽 6칸 이동 → `(100,260)`
4. 오른쪽 6칸 이동 → `(340,260)`
5. 아래쪽 9칸 이동 → `(340,620)`
6. 오른쪽 7칸 이동 → `(620,620)`, 도착

정답 코드는 최종 좌표 `(620, 620)`과 벽 21칸을 `assert`로 검증합니다. 이 예시는 **경로 실행 + 충돌 방지**이며, BFS/DFS를 활용한 자율 미로 탐색은 별도의 심화 미션입니다.
