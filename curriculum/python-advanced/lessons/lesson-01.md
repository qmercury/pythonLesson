## 이론 (20분)

2차원 리스트는 행·열을 이용해 장소의 종류를 기록한다. 리스트의 `room[y][x]`는 y행의 x열을 뜻한다. 튜플 `(x, y)`는 좌표 하나를 표현하고, 집합 `set`은 중복 방문을 자동으로 제거한다. 청소율은 (청소 완료 칸 수 / 이동 가능한 칸 수) × 100이다.

## 짧은 예시

`room = [[0, 0], [1, 0]]`에서 `room[1][0]`은 장애물(1)이다. `cleaned.add((2, 4))`는 같은 좌표를 여러 번 추가해도 한 번만 기록한다.

## 보충 이론: 좌표와 집합을 쓰는 이유

### ① 2차원 리스트의 구조

```python
room = [
    ['.', '.', '#'],
    ['D', '.', '.']
]
print(room[0][2])  # '#'
print(room[1][0])  # 'D'
```

파이썬 리스트는 `room[행][열]` 순서다. **행이 y, 열이 x**라고 약속하면 `room[y][x]`로 조회한다. Turtle 좌표처럼 y가 위로 증가하는 좌표계가 아니므로, 학생에게 인덱스와 실제 공간 좌표를 구분하도록 설명한다.

### ② 리스트와 집합 비교

```python
route = [(0, 4), (1, 4), (1, 4)]
cleaned = set(route)
print(len(route))      # 3회 방문
print(len(cleaned))    # 서로 다른 2개 위치
```

- `list`: 순서, 중복, 주행 과정을 보관하는 데 적합
- `set`: 중복 없이 방문 장소를 기록하고 `in`으로 확인할 때 적합
- `tuple`: `(x, y)`라는 변하지 않는 좌표 쌍을 표현하며 집합의 요소로 사용 가능

### ③ 실험 활동

`level=1`을 사용해 0%, 50% 근처, 100% 청소율을 만들어 본다. 장애물 `#`를 청소한 칸으로 계산하면 안 된다. 첫 번째 프로그램에서는 `for`를 사용해 방의 모든 칸을 검사하고, 두 번째에서는 특정 좌표들을 직접 `add()`해서 청소율을 비교한다.
