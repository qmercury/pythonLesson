## 이론 (20분)

너비 우선 탐색(BFS)은 시작점에서 한 칸 떨어진 곳, 두 칸 떨어진 곳 순서로 방문한다. `deque`의 `popleft()`를 이용하면 먼저 들어온 좌표부터 꺼낼 수 있다. 최초로 발견한 이전 좌표를 딕셔너리에 저장하면 목표에서 출발점으로 경로를 복원할 수 있다. 모든 이동 비용이 같을 때 최단 이동 횟수를 보장한다.

## 짧은 예시

`queue = deque([start])`, `previous = {start: None}`으로 시작하고, 이웃을 새로 발견할 때 `previous[next] = current`로 기록한다.

## 보충 이론: BFS의 원리

DFS가 한 길을 끝까지 탐색한다면, BFS는 현재 위치에서 **한 칸 거리인 모든 곳을 먼저 확인**한다. 이동 비용이 모든 칸에서 동일하면 가장 먼저 목표를 발견한 경로가 최단 이동 횟수 경로다.

### 자료구조: 큐(Queue)

```python
from collections import deque
queue = deque([(0, 0)])
queue.append((1, 0))
here = queue.popleft()
```

큐는 먼저 들어온 것이 먼저 나온다(FIFO). 리스트의 `pop()`은 끝에서 꺼내므로 스택처럼 동작한다.

### 딕셔너리로 지나온 길 기억하기

```python
previous = {(0, 0): None}
previous[(1, 0)] = (0, 0)
previous[(2, 0)] = (1, 0)
```

이 저장 방식은 `(2,0)`에 도착하려면 어디서 왔는지 알려 준다. 목표에서 거꾸로 이전 위치를 따라간 뒤 `reverse()`하면 출발점부터 목표까지의 경로가 된다.
