## 이론 (20분)

프로그램의 리스트와 딕셔너리는 실행이 종료되면 사라진다. JSON은 데이터를 텍스트 파일로 저장하는 표준 형식이다. Python 튜플은 JSON에 저장될 때 배열이 되므로 다시 불러오면 리스트가 된다. 경로를 좌표 튜플로 사용하려면 `tuple()`로 변환한다.

## 짧은 예시

`json.dump(data, file)`로 저장하고 `json.load(file)`로 불러온다. `with open(...)`은 작업이 끝나면 파일을 닫는다.

## 보충 이론: 프로그램이 종료돼도 정보를 남기려면

### JSON 구조

```json
{
  "level": 1,
  "route": [[0, 4], [1, 4], [2, 4]],
  "steps": 2
}
```

파이썬 딕셔너리는 JSON의 객체, 리스트와 튜플은 JSON의 배열로 저장된다. `set`은 JSON으로 바로 저장되지 않으므로 리스트 등으로 변환해야 한다.

### 파일 저장 기본 형태

```python
import json
with open('cleaning_record.json', 'w', encoding='utf-8') as file:
    json.dump({'level': 1, 'route': [[0, 4]]}, file, indent=2)
```

파일 읽기는 `'r'` 모드를 사용한다. 저장 위치가 바뀌는 문제를 줄이려면 `Path(__file__).with_name(...)`처럼 현재 파일의 위치를 기준으로 저장한다.

### 오류를 학습 기회로 활용

- 파일이 없을 때: `FileNotFoundError`
- JSON 문법이 깨졌을 때: `json.JSONDecodeError`
- 튜플을 저장했다가 읽었을 때 리스트가 되는 현상
