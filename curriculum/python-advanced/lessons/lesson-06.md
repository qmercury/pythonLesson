## 이론 (20분)

Tkinter는 버튼, 라벨, 창 같은 GUI 요소를 만든다. `Canvas`의 직사각형은 `(왼쪽, 위, 오른쪽, 아래)` 픽셀 좌표로 그린다. 격자 좌표 `(x, y)`에 칸 크기 CELL을 곱하면 화면의 사각형 위치가 된다. 클릭 이벤트로 좌표를 구해 데이터와 화면을 함께 갱신해야 한다.

## 짧은 예시

`canvas.create_rectangle(x*CELL, y*CELL, (x+1)*CELL, (y+1)*CELL)`로 한 칸을 그린다. 클릭 좌표는 `event.x // CELL`처럼 변환한다.

## 보충 이론: 화면 좌표와 데이터 좌표 연결

Tkinter에서는 창을 생성한 뒤 `root.mainloop()`로 이벤트를 기다린다. 버튼 클릭·캔버스 클릭·키 입력이 있을 때 등록된 함수가 호출된다.

### 격자 좌표를 픽셀로 변환

CELL=50일 때 `(x, y)=(2, 1)` 칸의 화면 영역은 `(100, 50, 150, 100)`이다.

```python
canvas.create_rectangle(x*CELL, y*CELL,
                        (x+1)*CELL, (y+1)*CELL,
                        fill='lightgreen')
```

클릭 이벤트의 픽셀 좌표를 격자 좌표로 돌릴 때는 `event.x // CELL` 및 `event.y // CELL`을 이용한다.

**핵심:** 실제 상태는 `cleaned` 집합에 저장하고, 화면은 그 상태를 읽어 다시 그린다. Canvas에 녹색 칸을 그렸다고 해서 `cleaned` 집합이 자동으로 변하지는 않는다.

### 실습 확장

- 가구는 회색, 미청소 바닥은 베이지, 청소 칸은 연두색
- 마우스로 칸을 선택해 `cleaned.add()` 실행
- 현재 좌표에 `R` 표시
- 라벨에 `cleaning_percent()` 값 표시
