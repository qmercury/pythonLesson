# Python 크리에이티브 코딩 1 — Turtle (12차시)

> SPIKE Prime에서 익힌 이동·회전·조건·반복·함수를 화면 속 그래픽, 게임, 로봇 시뮬레이션에 적용한다.

- 대상: SPIKE Prime Python 기초(변수, 조건문, 반복문, 함수) 학습자 / 초등 4~6학년 권장
- 시간: 회당 90분(수준별 조정)
- 도구: Thonny + 데스크톱 Python + 표준 라이브러리 turtle
- 최종 결과: 학생이 직접 설계한 인터랙티브 게임 또는 가상 주행로봇 시뮬레이터

## 학습 목표

1. 이동·회전·좌표·각도를 활용해 화면 속 객체를 제어한다.
2. 반복문, 함수, 리스트로 규칙적인 그래픽과 이동 경로를 작성한다.
3. 키보드·마우스 이벤트와 조건문을 사용해 상호작용을 구현한다.
4. 충돌, 거리, 가상 센서의 동작 원리를 수학과 코드로 구현한다.
5. 자신의 프로젝트를 설계·테스트·개선하고 기능을 설명한다.

## 차시별 지도 및 미션

### 01 — 화면 속 거북이 로봇
- 질문: 실제 SPIKE Prime이 사각형을 주행하듯 화면에도 그릴 수 있을까?
- 새 개념: Turtle 객체, forward/backward, left/right, 펜, speed.
- 교사 시연: 사각형 주행을 하면서 실제 로봇의 이동과 픽셀 단위 이동의 차이를 비교.
- **기본** 사각형과 삼각형 그리기 / **응용** 정육각형 그리기 / **도전** 변의 개수를 전달받는 draw_polygon(n, length) 함수.
- 결과물: 도형 3종을 그리는 프로그램.
- 점검: 정다각형 외각은 360 ÷ 변의 개수임을 설명한다.

### 02 — 수학으로 그림 만들기
- 질문: 같은 도형을 반복하는데 왜 꽃무늬가 될까?
- 새 개념: 중첩 반복문, 반복 간 회전 각도, 색상 리스트, 나머지 연산.
- **기본** 사각형을 반복 회전 / **응용** 길이·각도·색상을 변수로 변경 / **도전** 매개변수로 패턴을 만드는 함수.
- 결과물: 자신만의 알고리즘 아트.
- 점검: 변경한 숫자와 화면 패턴의 관계를 설명한다.

### 03 — 좌표로 그림 그리기
- 질문: 화면 위의 원하는 위치로 정확히 이동하려면?
- 새 개념: 원점 (0,0), xcor/ycor, goto, penup/pendown, 좌표 쌍.
- **기본** 네 좌표를 연결 / **응용** 집·자동차·로봇의 외곽선 제작 / **도전** 좌표 목록을 반복문으로 순회.
- 결과물: 좌표를 이용한 그림.
- 점검: 왼쪽으로 이동하면 x가 감소하는 것을 안다.

### 04 — 키보드로 조종하기
- 질문: 코드가 정해 둔 동작이 아니라 사용자의 키 입력에 반응하려면?
- 새 개념: screen.onkey, screen.listen, 함수 참조, 이벤트.
- **기본** 방향키 전진·후진·회전 / **응용** 속도 변경 / **도전** 화면 경계 검사.
- 결과물: 키보드로 조종하는 캐릭터.
- 점검: onkey에 함수 호출 결과가 아닌 함수 자체를 연결하는 이유를 설명한다.

### 05 — 목표 지점 찾아가기
- 질문: 보물에 도착했는지 컴퓨터는 어떻게 알까?
- 새 개념: distance, 비교 조건, 목표 위치, random.
- **기본** 목표와의 거리가 임계값 이하면 성공 / **응용** 다수 목표 수집 / **도전** 목표 무작위 배치와 점수 증가.
- 결과물: 보물찾기 게임.
- 점검: 거리를 계산하는 대상과 도착 기준을 설명한다.

### 06 — 장애물 피하기
- 질문: 눈으로 보이는 빨간 사각형을 컴퓨터는 어떻게 막을까?
- 새 개념: 직사각형 범위 조건, and/or, 이전 위치 보관, 충돌 처리.
- **기본** 장애물 1개 / **응용** 장애물 목록 / **도전** 장애물과 목표가 있는 직접 설계 미로.
- 결과물: 미로 탈출 게임.
- 점검: Turtle 중심만 검사하면 그림 일부가 겹칠 수 있고 큰 이동량으로 장애물을 건너뛸 수 있음을 안다.

### 07 — 점수·시간·재시작
- 질문: 게임에서 남은 시간과 점수는 어떻게 계속 바뀔까?
- 새 개념: 전역/상태 변수, write/clear, Screen.ontimer, 게임 종료 상태.
- **기본** 점수 표시 / **응용** 제한시간 표시 / **도전** 시작·종료·재시작 흐름.
- 결과물: 한 판 플레이 가능한 게임.
- 점검: GUI 이벤트 루프 안에서 time.sleep()으로 화면을 막지 않는다.

### 08 — 가상 센서 만들기
- 질문: 실제 센서 없이도 장애물까지 거리를 측정할 수 있을까?
- 새 개념: 위치 간 거리, towards, heading, 감지 범위와 방향 조건.
- **기본** 목표/장애물까지 거리 숫자로 표현 / **응용** 임계 거리 이내 경고 / **도전** 전방 방향의 물체만 판정.
- 결과물: 가상 거리센서 시연.
- 점검: 이것은 실제 센서 입력이 아니라 가상 좌표를 계산한 결과라고 구분한다.

### 09 — 자동으로 이동하기
- 질문: 키보드 없이 스스로 목적지로 움직이게 하려면?
- 새 개념: 단계별 명령, 상태 변화, 이동 함수 재사용, 위치·방향 업데이트.
- **기본** 미리 정한 명령 목록 실행 / **응용** 장애물 발견 시 정지·회전 / **도전** 단순 장애물 회피 규칙.
- 결과물: 자동주행 로봇.
- 점검: 자율 동작도 학생이 만든 알고리즘의 결과임을 설명한다.

### 10 — 경로 비교와 탐색
- 질문: 장애물을 피하는 길이 여러 개일 때 어느 길이 짧을까?
- 새 개념: 격자 지도, 경로 목록, 거리/이동 횟수 비교, 탐색 알고리즘.
- **기본** 두 경로의 칸 수 비교 / **응용** 최적 경로를 저장하고 실행 / **도전** BFS로 최단 경로 탐색.
- 결과물: 경로 탐색 시뮬레이터.
- 점검: BFS는 심화 선택 과제이며 모든 학생에게 의무화하지 않는다.

### 11 — 자유 프로젝트 기획·구현
- 선택: 미로 탈출 / 보물찾기 / 가상 로봇축구 / 자동주행 / 그래픽 아트 생성기.
- 준비: 사용자, 규칙, 화면 구성, 필수 기능 3개, 함수 목록, 미션 분담.
- **기본** 필수 기능 2개 동작 / **응용** 점수·시간 등 확장 / **도전** 독자 알고리즘 추가.
- 결과물: 동작하는 1차 버전과 테스트 항목.

### 12 — 완성·테스트·발표
- 친구에게 프로그램을 사용하게 하고 실패 사례 2개 이상 기록.
- 문제 재현 → 원인 찾기 → 수정 → 재시험 진행.
- 발표: 해결하려는 문제, 핵심 알고리즘, 직접 변경한 부분, 다음 버전 계획.
- 결과물: 실행 가능한 최종 작품 + 화면 캡처 + 연구일지.

## 1차시 시작 코드

~~~python
import turtle

screen = turtle.Screen()
screen.title("Robot Mission")

robot = turtle.Turtle()
robot.shape("turtle")
robot.color("blue")

for _ in range(4):
    robot.forward(100)
    robot.left(90)

screen.mainloop()
~~~

## 수업 운영 참고
- 각 수업 구성: 도입 10분 → 개념/시범 20분 → 미션 40분 → 확장 10분 → 발표·기록 10분.
- 좌표와 거리 단위는 화면 좌표이며 실제 SPIKE Prime 로봇의 mm, 모터 회전량과 동일하지 않다.
- 로봇 프로그래밍 지식은 개념으로 연결하고, SPIKE 전용 라이브러리가 PC Python에서 실행된다고 가정하지 않는다.
- 예제의 기본 구조를 수정·설명하는 능력을 평가하며, 결과 화면만으로 평가하지 않는다.
