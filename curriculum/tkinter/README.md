# Python 크리에이티브 코딩 2 — Tkinter (12차시)

> GUI를 사용하는 사람이 이해할 수 있는 화면을 설계하고 버튼, 입력, 시간, 데이터와 연결해 실제 데스크톱 프로그램을 만든다.

- 대상: SPIKE Prime Python 기초 학습자, Turtle 과정 이수 시 더 수월함
- 시간: 회당 90분
- 도구: Thonny + 데스크톱 Python + tkinter/ttk
- 최종 결과: 학생이 구상한 작동하는 PC용 앱 1개
- 세부 지도안: [1차시 — 나의 첫 윈도우 프로그램](lesson-01.md)

## 학습 목표

1. 콘솔 출력과 GUI 위젯의 차이를 설명한다.
2. Label, Button, Entry, Frame 등으로 화면을 설계한다.
3. 이벤트와 함수를 연결하고 상태 변수를 업데이트한다.
4. 입력 검증, 타이머, 좌표, 파일 저장 기능을 조합한다.
5. 사용자가 겪을 오류를 재현·수정하고 개선한 앱을 발표한다.

## 차시별 지도 및 미션

### 01 — 첫 윈도우 프로그램
- 질문: 파이썬으로 클릭할 수 있는 컴퓨터 프로그램의 창을 만들 수 있을까?
- 새 개념: root=Tk(), title, geometry, Label, pack, mainloop.
- **기본** 자기 이름과 제목 표시 / **응용** 소개 문장·배경색 변경 / **도전** 글자/여백을 적절히 배치한 자기소개 화면.
- 결과물: '나의 첫 번째 앱'. 상세 안내는 [1차시 지도안](lesson-01.md).

### 02 — 버튼으로 조작하기
- 질문: 사용자가 누른 순간에만 코드를 실행하려면?
- 새 개념: Button(command=함수이름), 이벤트, IntVar 또는 Label 설정 변경.
- **기본** +1 점수 버튼 / **응용** -1과 초기화 / **도전** 두 팀 점수판 및 승리 조건.
- 결과물: 클릭 카운터. 함수 이름 뒤 괄호 유무 구분.

### 03 — 입력받고 보여주기
- 질문: 프로그램을 사용하는 사람이 정보를 직접 입력하게 하려면?
- 새 개념: Entry, get(), StringVar, 입력·출력 구분.
- **기본** 이름 입력 → 인사말 / **응용** 점수 입력 → 결과 메시지 / **도전** 비어 있는 값·잘못된 입력 안내.
- 결과물: 이름/점수 입력 앱.

### 04 — 화면 배치 설계
- 질문: 버튼을 원하는 위치에 가지런히 배치하려면?
- 새 개념: Frame, pack(), grid(row/column), 여백.
- **기본** 계산기 3×4 버튼 배치 / **응용** 제목·결과 영역 분리 / **도전** 창 크기 변경에도 보기 좋은 비율.
- 결과물: 기능 구현 전 계산기 화면.
- 주의: **같은 부모 위젯 안에 pack과 grid를 혼합하지 않음**. 서로 다른 Frame에서 따로 사용 가능.

### 05 — 계산기 동작 구현
- 질문: 입력한 문자열을 숫자로 바꿔 계산하려면?
- 새 개념: int/float, 사칙연산, 예외 처리(try/except), 0으로 나누기.
- **기본** 두 숫자의 덧셈·뺄셈 / **응용** 곱셈·나눗셈 / **도전** 입력 오류와 0 나누기를 안전하게 처리.
- 결과물: 작동하는 계산기.

### 06 — 퀴즈 또는 경기 점수판
- 질문: 선택 결과에 따라 프로그램 동작을 다르게 할 수 있을까?
- 새 개념: Radiobutton, Checkbutton, 값 판정, 점수 상태.
- **기본** 3문제 퀴즈 또는 2팀 점수판 / **응용** 정답 여부와 현재 점수 / **도전** 재시작, 최종 결과.
- 결과물: 선택형 인터랙티브 앱.

### 07 — 타이머·스톱워치
- 질문: 앱이 실행되는 중에도 시간이 계속 바뀌고 버튼이 눌리려면?
- 새 개념: after(), 상태(실행/일시정지/종료), 취소 처리, 경과 시간.
- **기본** 1초 단위 카운트 / **응용** 시작·일시정지·초기화 / **도전** 3분 경기 타이머와 종료 알림.
- 결과물: 로봇경기 타이머.
- 주의: GUI 메인 스레드에서 time.sleep()으로 멈추지 않는다. 정확도를 높이려면 실제 시간 차이로 남은 시간을 계산한다.

### 08 — Canvas 가상 로봇
- 질문: 버튼을 누를 때마다 화면 속 도형을 움직일 수 있을까?
- 새 개념: Canvas, create_rectangle/create_oval, coords/move, 상대 좌표.
- **기본** 방향 버튼 이동 / **응용** 현재 위치 표시 / **도전** 경계 넘어가지 않도록 조건 추가.
- 결과물: 가상 로봇 제어 패널.

### 09 — 키보드·충돌 판정
- 질문: 화면의 벽과 캐릭터가 부딪혔는지 어떻게 판단할까?
- 새 개념: bind, 좌표 범위, 충돌 판정, 게임 상태.
- **기본** 방향키 조작 / **응용** 장애물 2개 / **도전** 목표까지 도착하는 미니게임.
- 결과물: 장애물 피하기 게임.
- 주의: Canvas의 좌표 원점은 보통 **좌상단(0,0)**이며 y는 아래로 증가해 기본 Turtle 좌표계와 다르다.

### 10 — 기록 저장·읽기
- 질문: 앱을 종료한 뒤에도 점수와 기록이 남아 있도록 하려면?
- 새 개념: 리스트, csv.reader/writer, 파일 경로, 목록 위젯.
- **기본** 팀·기록 입력과 목록 출력 / **응용** CSV 저장·읽기 / **도전** 정렬 및 최고 기록 표시.
- 결과물: 경기 기록 관리 앱.
- 주의: 학생 실명·연락처 같은 개인정보 대신 가명/임의 데이터를 사용한다.

### 11 — 자유 프로젝트 개발
- 선택: 퀴즈 / 로봇경기 점수판 / 할 일 관리 / 간단 그림판 / 기록 관리.
- 기획서: 사용자, 해결 문제, 필요한 위젯, 필수 기능 3개, 예상 오류.
- **기본** 주요 화면 구성 / **응용** 함수별 기능 구현 / **도전** CSV 저장 등 확장.
- 결과물: 테스트 가능한 앱 1차 버전.

### 12 — 완성·테스트·발표
- 다른 학생이 앱을 사용한 뒤 불편한 점 기록.
- 2가지 오류/예외 상황을 재현, 고치고 재검증.
- 발표: 핵심 코드 1개 설명, 사용자 시연, 개선 전후 비교.
- 결과물: 최종 앱 + 화면 캡처 + 포트폴리오.

## 2차시 준비 코드

~~~python
import tkinter as tk
from tkinter import ttk

root = tk.Tk()
root.title("점수판")
root.geometry("340x250")
score = tk.IntVar(value=0)

def add_point():
    score.set(score.get() + 1)

ttk.Label(root, text="로보타그램 점수판").pack(pady=15)
ttk.Label(root, textvariable=score, font=("Arial", 32)).pack(pady=15)
ttk.Button(root, text="+1점", command=add_point).pack()

root.mainloop()
~~~
