# 04차시 — 로봇 조종 화면 디자인

> 학생용 실습지 + 교사 안내 / 90분 / **교실 로컬 MQTT 브로커(필요 차시) 사용**

## 오늘의 목표
Tkinter 버튼을 명령 함수와 연결하고 공통 인터페이스를 만든다.

## 수업 시작 — 교사가 묻기 (0~10분)
실제 로봇 조종기를 보여 주며 버튼에 어떤 기능이 들어가야 하는지 학생에게 묻는다.

## 꼭 배울 개념 (10~25분)
`Button(command=...)`는 버튼 클릭 후 함수를 호출한다. 함수 호출을 등록할 때 `command=send`와 `command=send()`의 차이를 설명한다. `lambda`를 사용하면 `forward`, `left` 같은 매개변수를 넘길 수 있다.

### 교사가 직접 보여 주는 활동
`mqtt_controller.py`의 방향 버튼을 차례로 눌러 현재 송신 요청 표시를 확인한다. 이 단계에서는 모터를 연결하지 않는다.

## 학생 실습 (25~55분)
**기본 미션:** 전진·후진·좌회전·우회전·정지 버튼 각각의 명령 문자열을 표로 적는다.

## 더 해보기 (55~75분)
**응용:** 버튼 모양과 배치를 바꾸되 각 명령이 변하지 않는지 확인한다.

**도전:** 연결 상태에 따라 안내 문구가 어떻게 달라지는지 관찰하고 연결 불가를 알려 주는 디자인을 구상한다.

## 확인하고 기록하기 (75~90분)
- 내가 만든 화면이나 결과를 옆 학생에게 보여 준다.
- **생각 질문:** 다른 컴퓨터로 보낼 때 왜 함수와 화면 코드를 분리해 두면 좋을까요?
- **성공 기준:** 4방향 및 정지 버튼의 이름·동작 대응표를 완성하면 성취.
- 포트폴리오 2문장: "오늘 배운 통신 개념은 ______ 입니다." / "시험해 본 결과는 ______ 입니다."

## 교사용 지도 팁
- **자주 하는 실수:** 이 버튼은 조종 화면이지 모터 전원 스위치가 아니다. 실제 실행 여부는 status 회신이 있어야 확인할 수 있다.
- **설명/정답 포인트:** `lambda: command('forward')`는 버튼을 눌렀을 때에만 `command` 함수를 호출하게 한다.
- **수업 전 준비와 참고:** [mqtt_controller.py](../../../examples/mqtt-iot/mqtt_controller.py)
- **실물 로봇 주의:** EV3 Legendary 사용자 직렬 송수신 및 자동정지 기능이 검증되기 전에는 실제 모터에 연결하지 않는다.
