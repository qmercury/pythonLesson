# 10차시 — EV3 Legendary 통신 실습 준비

> 학생용 실습지 + 교사 안내 / 90분 / **장비별 검증 상태 확인 후 진행**

## 오늘의 목표
검증된 시리얼 수신 경로를 확인하고 하드웨어 실험의 순서를 설명한다.

## 수업 시작 — 교사가 묻기 (0~10분)
손 씻기 스테이션에서는 EV3 모터 회전을 컴퓨터가 받아 영상을 실행했어요. 이번에는 반대 방향도 필요합니다.

## 꼭 배울 개념 (10~25분)
'연결됨'은 데이터를 보내고 받는 프로그램이 완성됐다는 뜻이 아니다. 기존 v8은 EV3→PC 영상제어를 확인했다. PC→EV3 사용자 명령은 별도로 확인해야 한다. 블루투스 직렬 데이터 경계, 인코딩, 확인 메시지, 수신 프로그램의 허용 명령을 알아야 한다.

### 교사가 직접 보여 주는 활동
교사는 이미 검증한 v8 소스/동작 영상을 시연한다. 학생은 장치 목록 조회와 v8이 실제로 보낸 상태/데이터 형식을 관찰한다. 역방향 모터 제어는 교사가 검증을 완료하기 전에는 시뮬레이터에서만 진행한다.

## 학생 실습 (25~55분)
**기본 미션:** 송신 방향과 수신 방향을 화살표로 구분한다.

## 더 해보기 (55~75분)
**응용:** 모터 1개를 저속으로 잠깐 움직인 뒤 자동으로 멈추는 안전 시나리오를 설계한다.

**도전:** 실제 EV3의 센서값을 받아 Tkinter에 표시하려면 어떤 status 메시지가 필요한지 설계한다.

## 확인하고 기록하기 (75~90분)
- 내가 만든 화면이나 결과를 옆 학생에게 보여 준다.
- **생각 질문:** 어제 성공한 것은 EV3에서 PC로 가는 데이터였나요, PC에서 EV3를 움직이는 명령이었나요?
- **성공 기준:** 확인한 사실과 앞으로 검증할 내용을 구분하여 말하면 성취.
- 포트폴리오 2문장: "오늘 배운 통신 개념은 ______ 입니다." / "시험해 본 결과는 ______ 입니다."

## 교사용 지도 팁
- **자주 하는 실수:** EV3에서 임의 바이너리 전송이나 모터 구동을 하지 않는다. 모터는 초기에는 바퀴가 바닥에 닿지 않게 두고 교사 감독하에 실험한다.
- **설명/정답 포인트:** 기기·펌웨어·PC OS에 맞는 실제 사용자 송수신 API를 확인해야 하며, 동작 검증 전에는 실물 제어가 완료되었다고 평가하지 않는다.
- **수업 전 준비와 참고:** [EV3 설계 메모](../../../docs/ev3-legendary-serial.md), [포트 조사 코드](../../../examples/mqtt-iot/ev3_serial_ports.py)
- **실물 로봇 주의:** EV3 Legendary 사용자 직렬 송수신 및 자동정지 기능이 검증되기 전에는 실제 모터에 연결하지 않는다.
