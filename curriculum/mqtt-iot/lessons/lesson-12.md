# 12차시 — 다른 팀과 검증하고 발표

> 학생용 실습지 + 교사 안내 / 90분 / **장비별 검증 상태 확인 후 진행**

## 오늘의 목표
기술적인 성공뿐 아니라 안정성과 설명 능력을 평가한다.

## 수업 시작 — 교사가 묻기 (0~10분)
우리 팀이 잘 되었다고 생각해도 다른 팀이 사용하면 문제가 발견될 수 있어요.

## 꼭 배울 개념 (10~25분)
테스트는 '동작함' 확인뿐 아니라 정상·오류·연결 끊김을 실제로 시험하는 것이다. 실물 로봇에서는 자동 정지를 반드시 확인한다.

### 교사가 직접 보여 주는 활동
일부러 브로커 접속을 끊거나 서로 다른 토픽을 설정한 뒤 복구하는 절차를 시연한다(모터 없는 상태에서만).

## 학생 실습 (25~55분)
**기본 미션:** 정상 메시지 3개, 잘못된 토픽 1개, 연결 끊김 1개의 시험 결과를 기록한다.

## 더 해보기 (55~75분)
**응용:** 다른 팀과 송신/수신 역할을 교환하고 의도와 결과가 다른 상황을 설명한다.

**도전:** 버튼/UI 안내를 개선하고 오류 전후 화면을 비교한다.

## 확인하고 기록하기 (75~90분)
- 내가 만든 화면이나 결과를 옆 학생에게 보여 준다.
- **생각 질문:** 다음에 개선한다면 통신 안정성과 사용 편의성 중 어디를 먼저 바꾸겠어요?
- **성공 기준:** 시연 + 오류 1개 재현/해결 + 메시지 경로 설명으로 성취.
- 포트폴리오 2문장: "오늘 배운 통신 개념은 ______ 입니다." / "시험해 본 결과는 ______ 입니다."

## 교사용 지도 팁
- **자주 하는 실수:** 모터를 실제로 제어할 수 있는지 검증되지 않았다면 '실물 IoT 완성'으로 표시하지 않는다. 가상 로봇 시스템 완성으로 구분한다.
- **설명/정답 포인트:** 네트워크 연결·메시지 도착·명령 유효성·실제 동작 확인을 각각 다른 테스트 항목으로 기록한다.
- **수업 전 준비와 참고:** [교사용 점검표](../TEACHER-PRACTICE.md), [평가 기준](../TEACHER-HANDBOOK.md)
- **실물 로봇 주의:** EV3 Legendary 사용자 직렬 송수신 및 자동정지 기능이 검증되기 전에는 실제 모터에 연결하지 않는다.
