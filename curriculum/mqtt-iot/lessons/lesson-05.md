# 05차시 — JSON으로 로봇 명령 만들기

> 학생용 실습지 + 교사 안내 / 90분 / **교실 로컬 MQTT 브로커(필요 차시) 사용**

## 오늘의 목표
단순 문자열과 구조화된 JSON의 차이를 안다.

## 수업 시작 — 교사가 묻기 (0~10분)
'전진'만 적힌 쪽지로 로봇이 몇 초, 어느 속도로 움직여야 할지 알 수 있을까요? 라고 질문한다.

## 꼭 배울 개념 (10~25분)
JSON은 키-값 쌍으로 정보를 묶는다. `action`은 동작 종류, `duration_ms`는 요청 시간(ms), `speed_pct`는 속도 제한(%), `id`는 명령 식별자, `sent_at`은 생성 시간이다. `json.dumps`는 사전을 텍스트로, `json.loads`는 텍스트를 데이터로 바꾼다.

### 교사가 직접 보여 주는 활동
`protocol.py`의 `make_command('forward')`를 Thonny에서 호출한 뒤 반환된 사전의 키와 값을 확인한다. `json.dumps()` 결과를 출력해 본다.

## 학생 실습 (25~55분)
**기본 미션:** `forward`와 `stop` 명령의 JSON 필드를 비교한다.

## 더 해보기 (55~75분)
**응용:** `id`가 새 명령을 만들 때마다 달라지는 이유를 찾아본다.

**도전:** 너무 큰 speed_pct 값을 넣으면 오류가 나는 이유를 설명한다.

## 확인하고 기록하기 (75~90분)
- 내가 만든 화면이나 결과를 옆 학생에게 보여 준다.
- **생각 질문:** 메시지에 전송 시간이 들어 있으면 어떤 문제를 예방할 수 있나요?
- **성공 기준:** action·id·duration_ms를 올바르게 해석하면 성취.
- 포트폴리오 2문장: "오늘 배운 통신 개념은 ______ 입니다." / "시험해 본 결과는 ______ 입니다."

## 교사용 지도 팁
- **자주 하는 실수:** 예제의 시간·속도 숫자는 **수신 요청용 데이터**다. 현재 가상 로봇의 실제 애니메이션 속도와 정확히 일치하지 않는다.
- **설명/정답 포인트:** 보안·안전을 위해 허용된 동작만 받는다. 수신자가 임의의 Python 코드나 셸 명령을 실행하면 안 된다.

- **실물 로봇 주의:** EV3 Legendary 사용자 직렬 송수신 및 자동정지 기능이 검증되기 전에는 실제 모터에 연결하지 않는다.
