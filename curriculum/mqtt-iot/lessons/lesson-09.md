# 09차시 — MQTT와 EV3 Bluetooth 사이의 연결

> 학생용 실습지 + 교사 안내 / 90분 / **교실 로컬 MQTT 브로커(필요 차시) 사용**

## 오늘의 목표
MQTT와 Bluetooth 직렬통신을 다른 단계로 구분하고 로봇 브리지 기능을 설명한다.

## 수업 시작 — 교사가 묻기 (0~10분)
컴퓨터끼리는 Wi-Fi로 통신할 수 있는데 EV3는 어떻게 명령을 받을까요?

## 꼭 배울 개념 (10~25분)
A→브로커→B는 MQTT 통신이고, B→EV3는 Bluetooth Classic 직렬통신이다. B의 브리지 프로그램이 MQTT 명령을 해석해 EV3가 이해할 통신 데이터로 변환한다. **EV3 Legendary의 사용자 데이터 직렬 채널과 Pybricks 호스트 업로드 프로토콜을 혼동하지 않는다.**

### 교사가 직접 보여 주는 활동
기존 손 씻기 스테이션 v8의 EV3→Chrome Web Serial 연결 성공 사례를 학생들에게 소개한다. Python에서 포트 장치 이름을 조회하는 [ev3_serial_ports.py](../../../examples/mqtt-iot/ev3_serial_ports.py)를 실행하되 실제 데이터는 보내지 않는다.

## 학생 실습 (25~55분)
**기본 미션:** A, 브로커, B, EV3 네 개의 상자를 그리고 MQTT와 Bluetooth 통신 경로를 구별해 표시한다.

## 더 해보기 (55~75분)
**응용:** PC에서 시리얼포트가 보인다는 것과 실제 모터가 움직이는 것이 왜 다른지 이야기한다.

**도전:** `execute(action, duration_ms, speed_pct)`라는 공통 함수로 EV3와 가상 로봇의 차이를 감추는 설계를 한다.

## 확인하고 기록하기 (75~90분)
- 내가 만든 화면이나 결과를 옆 학생에게 보여 준다.
- **생각 질문:** 브로커는 블루투스로 EV3에 직접 접속할까요?
- **성공 기준:** 학생이 MQTT와 Bluetooth를 다른 통신 구간에 정확히 표시하면 성취.
- 포트폴리오 2문장: "오늘 배운 통신 개념은 ______ 입니다." / "시험해 본 결과는 ______ 입니다."

## 교사용 지도 팁
- **자주 하는 실수:** 과거 ev3dev Wi-Fi/SSH 실습 자료를 이번 Legendary 펌웨어의 실행 방법으로 사용하지 않는다.
- **설명/정답 포인트:** EV3 쪽 사용자 수신 프로토콜이 확실해지기 전에는 임의 문자열을 직렬포트로 전송하지 않는다.
- **수업 전 준비와 참고:** [EV3 직렬 설계](../../../docs/ev3-legendary-serial.md), [포트 확인](../../../examples/mqtt-iot/ev3_serial_ports.py)
- **실물 로봇 주의:** EV3 Legendary 사용자 직렬 송수신 및 자동정지 기능이 검증되기 전에는 실제 모터에 연결하지 않는다.
