# 03차시 — Tkinter로 두 컴퓨터 채팅

> 학생용 실습지 + 교사 안내 / 90분 / **교실 로컬 MQTT 브로커(필요 차시) 사용**

## 오늘의 목표
두 PC에서 Tkinter 앱을 실행하여 메시지를 주고받는다.

## 수업 시작 — 교사가 묻기 (0~10분)
채팅 앱의 전송 버튼을 누르면 메시지가 어느 길로 갈지 칠판에 화살표를 그린다.

## 꼭 배울 개념 (10~25분)
Paho MQTT는 네트워크 연결을 담당한다. `on_message`는 메시지가 오면 실행되는 함수다. `loop_start()`는 네트워크 처리를, `root.mainloop()`는 Tkinter 화면을 처리한다. 두 일이 동시에 진행되는 이유를 설명한다.

### 교사가 직접 보여 주는 활동
학생 A와 B 컴퓨터에서 `mqtt_chat.py`를 실행한다. 두 창 모두 'MQTT 연결됨'이 표시된 상태에서 A와 B가 번갈아 메시지를 전송한다.

## 학생 실습 (25~55분)
**기본 미션:** 서로 다른 별명을 입력하고 3개의 메시지를 주고받는다.

## 더 해보기 (55~75분)
**응용:** Enter로 송신하고 이름·메시지를 분리하여 화면에 표시되는지 관찰한다.

**도전:** A가 class01, B가 class02를 사용하면 왜 보이지 않는지 비교한 뒤 다시 맞춘다.

## 확인하고 기록하기 (75~90분)
- 내가 만든 화면이나 결과를 옆 학생에게 보여 준다.
- **생각 질문:** 하나의 프로그램에서 MQTT와 Tkinter가 어떻게 동시에 움직일까요?
- **성공 기준:** A↔B 왕복 메시지 1회 이상 성공하고 데이터 경로를 말로 설명하면 성취.
- 포트폴리오 2문장: "오늘 배운 통신 개념은 ______ 입니다." / "시험해 본 결과는 ______ 입니다."

## 교사용 지도 팁
- **자주 하는 실수:** Thonny에서 `ModuleNotFoundError: paho`가 나오면 Thonny가 사용하는 Python 인터프리터에 paho-mqtt를 설치한다.
- **설명/정답 포인트:** `on_message` 안에서 Tkinter 라벨을 직접 변경하는 대신 queue에 넣고 `root.after()`로 메인 스레드에서 처리한다.

- **실물 로봇 주의:** EV3 Legendary 사용자 직렬 송수신 및 자동정지 기능이 검증되기 전에는 실제 모터에 연결하지 않는다.
