# 03차시 — 콘솔로 양방향 MQTT 채팅하기

> 교사용 설명 + 학생용 실습 / 90분 / **Tkinter 사용하지 않음**

## 수업 목표

1. 한 컴퓨터가 **Publisher와 Subscriber 역할을 동시에 수행**한다는 것을 이해한다.
2. Thonny 콘솔에서 입력한 문장을 상대 컴퓨터의 콘솔에 표시한다.
3. `input()`, `print()`, `publish()`, `on_message()`의 역할을 설명한다.

## 도입 (0~10분)

지난 시간에는 A는 보내기만 하고 B는 받기만 했다. 질문: **"이번에는 B도 답장을 보내려면 어떻게 해야 할까?"**

```text
학생 A (publish + subscribe) ↔ MQTT 브로커 ↔ 학생 B (publish + subscribe)
   보내기: input()                                      보내기: input()
   받기:   print()                                      받기:   print()
```

## 교사 시연 (10~25분)

양쪽 PC에서 같은 파일 [step03_console_chat.py](../../../examples/mqtt-iot/step03_console_chat.py)를 실행한다. 브로커 접속 정보는 동일하게 설정한다.

각 컴퓨터의 예상 출력:

```text
[연결됨] 구독 토픽: robottagram/class01/chat

채팅을 시작합니다! (끝내려면 '종료' 입력)
나의 별명: A
보낼 메시지: 안녕!

[받음] A: 안녕!
```

B 컴퓨터에서도 `[받음] A: 안녕!`이 출력된다. **자기가 보낸 메시지도 자신에게 수신된다**는 점을 설명한다. 같은 Topic을 구독하고 있기 때문이다.

## 네 가지 핵심 명령

```python
message = input("보낼 메시지: ")     # 학생이 Shell에 문장을 입력
client.publish(TOPIC, message)      # 브로커에 메시지를 발행

def on_message(client, userdata, msg):  # 수신 시 자동 호출
    print(msg.payload.decode("utf-8"))  # Shell에 출력
```

**이 코드는 이해를 위한 발췌이며 단독으로 실행할 수 없다.** 실제 실행 프로그램에는 서버 연결, 콜백 등록, 네트워크 루프가 더 필요하다.

## 학생 실습 (25~55분)

- **기본:** A/B 각각 별명을 설정하고 3문장씩 채팅한다.
- **기본:** 프로그램에서 `TOPIC`이 어디에 설정되는지 찾는다.
- **응용:** 메시지를 보내기 전 `input()`에서 무엇을 반환하는지 설명한다.
- **도전:** B는 `class02`, A는 `class01`로 설정해 전송 실패가 아니라 **다른 채널의 메시지가 안 보이는 것**임을 구분한다.

## 생각 실험 (55~75분)

- 왜 받는 메시지는 버튼을 누르지 않아도 출력될까? → `on_message` 콜백이 자동 호출된다.
- `input()` 중인데도 메시지가 나타나는 이유는? → Paho의 `loop_start()`가 네트워크를 별도 스레드에서 처리한다.
- 두 사람이 거의 동시에 보내면 화면 글자가 서로 섞여 보일 수 있을까? → 콘솔 출력이 입력 프롬프트 사이에 섞일 수 있다. MQTT가 실패한 것은 아니다.

## 정리·발표 (75~90분)

**확인 질문:** "A도 Subscriber가 될 수 있나요?" → **네.** A/B 모두 Publish·Subscribe를 동시에 한다.

**성취 기준:** 두 PC에서 서로의 메시지를 받고, 수신 코드와 송신 코드를 찾아 설명한다.

**포트폴리오:** 오늘 주고받은 메시지 1개 / 새로 배운 함수의 역할 1개.

## 교사 참고

- 프로그램 종료는 Shell에서 `종료` 입력(또는 Thonny 중지).
- 이 프로그램은 실제 로봇·Tkinter GUI와 무관한 통신 기초 실습이다.
- 연결 오류는 IP/계정/토픽을 우선 점검한다.
- 초등학생은 모든 콜백과 스레드 구조를 암기하지 않는다. 처음에는 중요한 네 가지 명령만 설명하고 **콜백은 "메시지가 오면 자동 실행되는 함수"**로 소개한다.
